# Bluewake Rentals · demo concept

Demo για επιδείξεις σε πελάτες: φανταστική επιχείρηση **ενοικίασης σκαφών και scooter** με διαθεσιμότητα ανά όχημα. Δεν είναι πραγματική επιχείρηση και οι κρατήσεις δεν στέλνονται πουθενά.

Live: https://varveroglouvasileios.github.io/RentalProject/

## Τι δείχνει
- Κράτηση σκάφους (2 ώρες, 4 ώρες, ημέρα) ή scooter (1–14 ημέρες) με **άμεση τιμή**: το scooter έχει έκπτωση 10% από 3 ημέρες και 20% από 7 ημέρες.
- **Διαθεσιμότητα ανά όχημα**: η ώρα δείχνει πόσα οχήματα είναι ελεύθερα. Τα σκάφη επιστρέφουν έως τις 20:00 και έχουν 30΄ καθαρισμό μεταξύ ενοικιάσεων. Ο έλεγχος επαναλαμβάνεται κατά την επιβεβαίωση και ανατίθεται ελεύθερο όχημα.
- Προκαταβολή 30%, επιστρεφόμενη εγγύηση, και υποχρεωτική δήλωση διπλώματος για scooter.
- Πίνακας στόλου και κρατήσεων (`#/fleet`, κωδικός `demo`): παράδοση, επιστροφή, ακύρωση, κατάσταση κάθε οχήματος.

## Τεχνολογία
Vue 3, TypeScript, Tailwind, vue-router (hash history για GitHub Pages), Vitest. Η λογική (τιμολόγηση, ωράρια, επικαλύψεις, διαθεσιμότητα, επικύρωση) είναι καθαρές συναρτήσεις στο `src/lib/rental.ts` με tests. Τα δεδομένα μένουν στο `localStorage` και η διαχείριση έχει «Επαναφορά demo».

```bash
yarn install
yarn dev     # τοπικά
yarn test    # tests λογικής
yarn build   # production build
```

Οι φωτογραφίες είναι δημιουργημένες με AI και ενδεικτικές. Σχεδιασμός και υλοποίηση: Βασίλειος Βαρβέρογλου.
